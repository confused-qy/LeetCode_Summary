# Dynamic Programming (DP)

动态规划（Dynamic Programming, DP）是一种通过保存已经计算过的结果来避免重复计算的算法思想。它通常适用于具有**重叠子问题（Overlapping Subproblems）**和**最优子结构（Optimal Substructure）**的问题。DP 的核心思想是：把一个大问题拆分成多个小问题，先求解小问题，再利用小问题的结果得到大问题的答案。

在做动态规划题目时，第一步通常是定义状态（State）。状态表示我们当前要求解什么问题，例如 `dp[i]` 可以表示前 `i` 个元素的最优解，或者表示到达位置 `i` 的方案数。状态定义正确与否往往决定了题目是否能够顺利解决。

定义完状态后，需要找到状态转移方程（State Transition Equation）。状态转移方程描述当前状态如何由之前的状态推导出来。例如爬楼梯问题中：

dp[i] = dp[i-1] + dp[i-2]

表示到达第 `i` 阶的方法数等于到达前一阶和前两阶的方法数之和。

接下来需要考虑初始化（Initialization）。由于状态转移通常依赖于更小的状态，因此必须先给出最基础状态的值。例如爬楼梯问题中：

dp[1] = 1
dp[2] = 2

没有这些初始值，后续状态就无法计算。

动态规划一般有两种实现方式：

1. Top-down DP（记忆化搜索）
   - 使用 DFS + Memoization
   - 遇到子问题时递归求解
   - 计算过的结果保存下来避免重复计算

2. Bottom-up DP（递推）
   - 从最小状态开始计算
   - 按顺序推导到最终答案
   - 面试中更常见

动态规划的通用解题步骤：

1. 明确 dp 数组含义（状态定义）
2. 找到状态转移方程
3. 确定初始化条件
4. 确定遍历顺序
5. 手动推导小样例验证正确性
6. 编写代码并考虑空间优化

对于大部分 LeetCode DP 题，最重要的不是记公式，而是学会思考：

"dp[i] 表示什么？"

只要状态定义正确，状态转移方程通常会自然地推导出来。
